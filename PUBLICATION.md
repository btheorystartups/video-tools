## Publication checks and limitations

- Enumerated and retrieved all 1,076 tracked files at the pinned source commit.
- Checked file paths for common credential/secret filenames.
- Scanned retrieved text for common GitHub/API/AWS credential patterns, private-key headers, and literal secret assignments; no matches were found. This is a bounded pattern scan, not a comprehensive security audit.
- Raw videos, raw audio, full generated analysis directories, virtual environments, and credential files are not part of the tracked folder snapshot.
- Local shell/file tooling was unavailable during extraction, so unpublished local changes could not be compared and Python tests could not be executed.
- The original larger repository's tests outside this folder are not included by this folder-only extraction. No new runtime validation or production-readiness claim is made.

A root .gitignore excludes common local media, generated outputs, environments, and secret-file patterns from future accidental additions. Review any intended example dataset or portable package separately before publishing it.
