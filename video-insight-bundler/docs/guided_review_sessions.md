# Guided Review Sessions

V70 turns review registries into static guided workflows.

Generated files: `review_session_workbench.html`, `review_session_registry.json`, `review_session_step_index.json`, `review_session_checklists.json`, and `review_session_handoff_templates.md`.

Sessions include executive, recommendation, governance, evidence, interpretation, timeline/continuity, audit, diff/regression, and validation review.
