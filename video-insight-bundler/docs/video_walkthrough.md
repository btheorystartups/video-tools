# Portable video walkthrough

Open `demo_walkthrough.html` from the exported package (also linked near the top
of its landing page). Allow about five minutes:

1. Introduce the named video, selected segment time range, and recorded heuristic
   signal. Explain that this is a saved analysis snapshot, not a fresh analysis.
2. Open its video timeline and segment context. Segment boxes show time ranges.
3. Inspect the scoped segment signals and segment-matched recommendation on the
   walkthrough page; the full evidence and traceability galleries are optional. Cite the actual
   evidence and explain what the heuristic cannot establish. Use Back to return
   to the guided page between steps.
4. Record an accept/reject/open decision, evidence checked, uncertainty, and next
   action. Check the review checklist and download the notes JSON. Confirm the
   downloaded file exists before closing the page. If the browser does not save
   the download, copy the visible exported JSON into an external notes file.

Original video playback is intentionally excluded. Review against the original
media before editing; do not present priority/severity scores as verified audience
outcomes. Static notes and checklist state do not autosave or synchronize.

`validation/portable_fallback_link_audit.json` separately discloses HTML links
that resolve to missing-asset placeholders, including original references and
their source/profile classification where known. A clean broken-link validation
does not mean all source evidence was available. Do not demonstrate unavailable
features as working functionality.
