# Metric Card System

Phase 32 adds `dashboard/metric_card_registry.json` and `visualizations/metric_card_gallery.html`.

Metric cards are compact expert UI primitives. Each card includes metric name, category tag, severity badge, confidence badge, graph preview, current value, benchmark summary, interpretation, current status, optimization actions, and links for detail pages and compare workflows.

Supported modes are compact, expanded, dashboard, and detail-page. The registry also lists reusable primitives such as MetricCard, MetricDetailPage, GraphLegend, ThresholdOverlay, OptimizationPanel, EvidencePanel, BenchmarkComparison, SegmentDrilldownTable, ComparePanel, and TooltipDefinition.

The expert dashboard system provides deterministic editorial-review guidance and optimization interpretation. It does not apply edits, mutate media, infer identity, recognize faces, diagnose emotion, predict audience behavior, or make autonomous creative decisions. Human review is required before production or editorial changes.
