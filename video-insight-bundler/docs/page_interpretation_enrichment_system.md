# Page Interpretation Enrichment System

Every target dashboard/detail page receives visible expert sections: Expert Summary, What This Measures, Why It Matters, How To Read This, Good/Caution/Concerning Patterns, Current Values, Operational Interpretation, Optimization Options, What To Preserve, Related Evidence, Related Recommendations, What Not To Infer, Human Review Guidance, and Limitations.

The enrichment combines static page-family explanations, actual visible metrics/artifact references when available, deterministic fallback interpretation, optional LLM interpretation, evidence/recommendation linking, and limitation language.
