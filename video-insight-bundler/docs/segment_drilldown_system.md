# Segment Drilldown System

Phase 32 adds `dashboard/segment_drilldown_index.json`, `visualizations/segment_drilldown_index.html`, and `visualizations/detail/segment_drilldown_*.html`.

Segment drilldowns expose segment ID, timestamps, severity, related metrics, related recommendations, suggested review action, and evidence references. They support review of pacing spikes, rhetorical pressure regions, visual reset gaps, continuity breaks, acoustic spikes, and unresolved claim clusters when those signals are present in deterministic source artifacts.

Segment severity is a review prioritization heuristic. It does not diagnose emotion, infer intent, predict audience behavior, or apply edits.

The expert dashboard system provides deterministic editorial-review guidance and optimization interpretation. It does not apply edits, mutate media, infer identity, recognize faces, diagnose emotion, predict audience behavior, or make autonomous creative decisions. Human review is required before production or editorial changes.
## Segment Context Panels

Phase 33 adds timeline-oriented segment context panels for high-priority regions. Panels summarize pacing, rhetorical, visual, topic continuity, recommendation, blocker, evidence, preservation, review, and non-inference context.
